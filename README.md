# OCEAN / iOceans — Controlled Evolution Mockup

This repository contains a navigable mockup for a controlled evolution layer around iOceans.

Objective: do not replace iOceans. Do not sell another product. Secure, order and integrate.

## What this is

A Vue 3 + TypeScript mockup using synthetic demo data, internal screens, controlled fixtures, visible states, roles, logs, governed AI simulations and phased budget logic.

## What this is not

- Not production.
- Not connected to real iOceans systems.
- Not connected to external APIs.
- Not using real scientific data.
- Not using credentials.
- Not importing raw MR. WOLF_ or OES Funding Radar HTML.

## Commands

Install: npm install

Run: npm run dev

Sensitive check: npm run check:sensitive

Demo data check: npm run check:demo-data

Typecheck: npm run typecheck

Lint: npm run lint

Build: npm run build

## Core principle

Make the system obvious.
