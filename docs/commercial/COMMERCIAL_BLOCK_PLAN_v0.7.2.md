# Commercial Block Plan — OCEAN / iOceans v0.7.2

## Purpose

This document defines the commercial entry model for moving from controlled mockup review into a paid, phased and executable first contract.

The project should not be presented as one open-ended programme.

It should be presented as two blocks.

The client first contracts Block 1.

## Commercial structure

| Block | Meaning | Amount | Status |
|---|---|---:|---|
| Block 1 | First contracted block | 45,000 EUR + VAT | Contract first |
| Block 2 | Expansion, integration and hardening reference | 105,000 EUR + VAT | Deferred |
| Total programme reference | Block 1 + Block 2 | 150,000 EUR + VAT | Not contracted upfront |

## Core principle

Block 1 is the professional entry point.

Block 2 is not sold as the first decision.

The first decision should be controlled, understandable and executable.

## Block 1 — First contracted block

Amount:

45,000 EUR + VAT

Block 1 is divided into seven uneven phases. The phases are not equal because the work is not equal.

Each phase is priced according to task weight, decision value and delivery risk.

## Block 1 phase breakdown

| Phase | Scope | Amount |
|---|---|---:|
| Phase 0 | Alignment, scope and executive decision | 7,500 EUR + VAT |
| Phase 1 | Operational data model | 6,000 EUR + VAT |
| Phase 2 | Scientific evidence, states and review | 8,000 EUR + VAT |
| Phase 3 | Budget, opportunities and executive control | 4,500 EUR + VAT |
| Phase 4 | AI governance | 5,500 EUR + VAT |
| Phase 5 | Technical contract, fixtures and reproducible validation | 6,000 EUR + VAT |
| Phase 6 | Handoff, demo, video and Block 2 decision | 7,500 EUR + VAT |

Total:

45,000 EUR + VAT

## Why the phases are uneven

The phases are priced by task value.

Scientific evidence, review states and non-overclaiming guardrails carry more weight than a simple executive budget frame.

Handoff, demo and Block 2 decision support also carry weight because they convert Block 1 into a decision-ready path for the next block.

This is more professional than splitting 45,000 EUR into artificial equal parts.

## Block 2

Block 2 reference:

105,000 EUR + VAT

Block 2 should remain deferred.

It may include future expansion, real integrations, production hardening, rollout support and broader operational implementation.

Block 2 should only be discussed after Block 1 produces:

- validated entities
- agreed states
- agreed evidence model
- agreed review gates
- validated demo package
- clear executive decision basis

## What this is not

This is not a blank cheque.

This is not a production implementation commitment.

This is not a real-data integration commitment at mockup stage.

This is not an open-ended consulting period.

This is a controlled commercial path from mockup review to a first paid project block.
