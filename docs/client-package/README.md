# OCEAN / iOceans Client Package

This folder contains the structured client-facing review package for the controlled OCEAN / iOceans mockup.

It is intentionally separated from application code.

## Contents

- 00_LEER_PRIMERO: first reading, scope and limits
- 01_DOCUMENTOS_BASE: base documents
- 02_DATA_DEMO: synthetic demo data reference
- 03_PANTALLAS: screen matrix and screen explanations
- 04_COMPONENTES: component documentation
- 05_HERRAMIENTAS_INTERNAS_DEMO: internal-tool demo specifications
- 06_IA_GOBERNADA_DEMO: governed AI criteria and synthetic prompts
- 07_OFERTAS_PROPUESTAS_DEMO: opportunity and proposal demo model
- 08_LOGS_Y_ESTADOS: logs, states and traceability model
- 09_GUION_DEMO: demo script and pre-OCEAN checklist
- 10_EXPORT_CLIENTE: client export notes

## Delivery rule

This folder is for review and controlled delivery.

It must not contain real OCEAN data, credentials, external API keys, real scientific measurements or internal-only material.

## Mr.Wolf workstream

Mr.Wolf is included as an internal OCEAN capability to be framed, governed and prepared for future integration.

The mockup does not replace Mr.Wolf, does not rebuild it from scratch and does not connect to real Mr.Wolf systems.

The review objective is to show how Mr.Wolf can become visible inside a controlled operating model: entities, states, evidence, review gates, audit logs and AI boundaries.
